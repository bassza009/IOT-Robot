# Robot line follower — Full speed / แหล่งจ่ายที่แจ้ง 6.8 V

สำเนาแยกจาก `robotline_simple` รุ่นที่ผู้ใช้ยืนยันว่าวิ่งได้ต่อเนื่อง
ใช้โค้ดควบคุมเดียวกันทุกบรรทัด เปลี่ยนเฉพาะค่าจูนใน `Settings.h`
โฟลเดอร์นี้เปิดและอัปโหลดได้เอง ไม่ต้องใช้ไฟล์จากรุ่นเดิม

## เปิดใช้งาน

1. เปิด `robotline_fullspeed.ino` ใน Arduino IDE โดยเก็บ `Settings.h` ไว้ในโฟลเดอร์เดียวกัน
2. เลือกบอร์ด **Arduino UNO R4 WiFi** แล้วอัปโหลด
3. หุ่นเริ่มตามเส้นหลัง setup เสร็จ ไม่มี countdown หรือคำสั่ง START
4. ถ้าต้องการกลับไปใช้รุ่นที่วิ่งผ่านสนามแล้ว ให้อัปโหลด `robotline_simple.ino`

ถ้าใช้ไฟล์ ZIP ให้แตกไฟล์ทั้งโฟลเดอร์ก่อนเปิดสเก็ตช์
รุ่นเต็มสปีดนี้ผ่านการตรวจซอฟต์แวร์ แต่ยังไม่ได้ทดสอบวิ่งจริงที่ 6.8 V

## ค่าจูนหลัก

| ค่า | รุ่น simple | รุ่น fullspeed |
| --- | --- | --- |
| `BASE_SPEED` ทางตรง | 160 | **255** |
| `MAX_SPEED` เพดาน PWM | 240 | **255** |
| `TURN_SPEED` หมุนเข้ามุม | 210 | **255** |
| `STEERING_KP` แรงแก้โค้ง | 80 | **128** |
| `SEARCH_SPEED` หมุนหาเส้น | 160 | 160 |
| `REVERSE_SPEED` ถอยหาเส้น | 160 | 160 |
| `CROSS_SPEED` ผ่านดำครบห้าจุด | 110 | 110 |
| `RIGHT_TRIM` ชดเชยล้อขวา | 46800 / 55500 | 46800 / 55500 |

PWM ใช้ช่วง 0–255 โดย 255 คือเปิด enable เต็ม duty cycle
ทางตรงจึงสั่งซ้าย **255** และขวา **215** หลังชดเชยกำลังมอเตอร์ด้วยค่าที่ใช้แล้ววิ่งดี
ขณะเลี้ยวจะลดล้อด้านในและจำกัดคำสั่งทุกล้อไม่ให้เกิน 255
มุมคมใช้ล้อหมุนสวนกัน ส่วนการค้นหาและถอยใช้ค่าของรุ่นที่ทดสอบแล้ว

`STEERING_KP=128` มาจากการเพิ่มตามสัดส่วน `80 × 255 / 160`
เป็นค่าจูนเริ่มต้น ไม่ใช่ผลวัดจากสนามที่ความเร็วใหม่
ถ้าส่ายให้ลด `STEERING_KP` ทีละ 5; ถ้าหมุนเลยเส้นให้ลด `TURN_SPEED` ทีละ 10
หากหลุดเส้นที่ความเร็วใหม่ ให้ลด `BASE_SPEED` หรือกลับไปใช้รุ่น simple

**6.8 V** คือแรงดันแหล่งจ่ายที่ผู้ใช้แจ้ง โค้ดไม่มีการวัดแบตเตอรี่หรือควบคุมแรงดัน
จึงไม่มีค่าตั้ง 6.8 V ในโปรแกรมเพื่อทำให้แรงดันจ่ายเปลี่ยน
PWM 255 ไม่ได้ยืนยันแรงดันที่ขั้วมอเตอร์หรือความเร็ว RPM จริง

## การต่อสายและเซนเซอร์

| ส่วน | ขา |
| --- | --- |
| เซนเซอร์ซ้าย → ขวา | A5, A4, A3, A2, A1 |
| มอเตอร์ซ้าย | PWM D5, ทิศทาง D6 / D7 |
| มอเตอร์ขวา | PWM D10, ทิศทาง D9 / D8 |

ADC 12 บิต; ค่าเริ่มต้นพื้น `3000` และดำ `900` ทั้งห้าช่อง
แก้ `FLOOR_RAW`, `BLACK_RAW` ตามค่าที่วัดได้แต่ละช่อง
`LINE_THRESHOLD=450` คิดจากพื้น=0 และดำ=1000; ด้วยค่าเริ่มต้น RAW ≤ 2055 นับเป็นดำ
ไม่ใช้ BLE, encoder หรือไลบรารีเสริม

## หลุดเส้นและไฟสถานะ

- หลุดเส้นแต่รู้ด้านล่าสุด: หมุนหาเส้นไม่เกิน 600 ms แล้วถอย
- ไม่รู้ด้าน, เส้นแยกหลายกลุ่ม, เลี้ยวเกิน 1800 ms หรือดำครบห้าจุดเกิน 250 ms: ถอยหาเส้น
- เบรก 80 ms ก่อนถอย; ถอยด้วย PWM ซ้าย -160 ขวา -134 ไม่เกิน 650 ms
- เจอเส้นที่ตามต่อได้: เบรกก่อนกลับตามเส้น
- ถอยครบเวลา: `WAIT_LINE` หยุดรอ เมื่อเจอเส้นปกติจะกลับวิ่งเองโดยไม่ต้อง RESET

| ไฟ L | สถานะ |
| --- | --- |
| ติดค้าง | ตามเส้น / เลี้ยว / หมุนหาเส้น |
| กระพริบเร็ว | ถอยหาเส้น |
| กระพริบครั้งเดียวต่อวินาที | รอเส้น |
| กระพริบเป็นคู่ทุก 1.5 วินาที | STOP หรือข้อผิดพลาดระบบ ต้อง RESET |
| ดับช่วงสั้น | เบรกก่อนเปลี่ยนทิศ |

Serial Monitor **115200 baud** แสดง `STATE`, `LAST_ERROR`, `RAW`, `MASK`, `ERR`, `PWM`
ส่ง `STOP` เพื่อหยุดได้ทุกช่วง รวมถึงตอนวิ่งเต็มกำลัง ถอย หรือรอเส้น
STOP ค้างจน RESET; ค่าตั้งเซนเซอร์ผิดและ `CONTROL_OVERRUN` ก็หยุดค้างเช่นกัน

## ตรวจซอฟต์แวร์

รันจากโฟลเดอร์ `Robot`:

```sh
python3 robotline_fullspeed/tests/run_tests.py
arduino-cli compile --fqbn arduino:renesas_uno:unor4wifi --warnings all robotline_fullspeed
```

ชุดทดสอบรันสเก็ตช์จริงกับ Arduino I/O จำลอง ตรวจ PWM เต็มกำลังและการเลี้ยวเมื่อ
ล้อถึงเพดาน 255 รวมถึง STOP, การถอย, กลับตามเส้น, เวลาควบคุม และ Serial
การทดสอบนี้ไม่จำลองแรงดัน แบตเตอรี่ แรงเสียดทาน หรือรูปสนามจริง
