# Hyper-Dash 3 — เปิดวิ่งอัตโนมัติ

**ค่าเริ่มต้นเปิดขับมอเตอร์แล้วตามคำขอ** เมื่อเปิดเครื่องหรือ RESET จะเริ่มตามเส้น
โดยไม่ต้องต่อ Serial หรือส่งคำสั่งเริ่มวิ่ง ตั้งทางตรง PWM 160 และเพดานขณะขับ 180
จาก 255 เพิ่มจากรุ่น PWM 100 ที่ผู้ใช้รายงานว่ามอเตอร์ไม่หมุน ค่าชุดใหม่นี้ยังไม่ได้
ทดสอบกับ Hyper-Dash 3 จริง จึงยังยืนยันไม่ได้ว่าจะเริ่มหมุนภายใต้โหลดจริง

L298N + 6.8 V ยังมีข้อจำกัดด้านแรงดันและกระแสตามด้านล่าง การปลดล็อกซอฟต์แวร์
และลด PWM ไม่ได้แก้ข้อจำกัดเหล่านี้ มอเตอร์หรือไดรเวอร์ยังอาจร้อนหรือเสียหายได้

โปรไฟล์นี้แยกจาก `robotline_simple` และ `robotline_fullspeed`
เก็บการตามเส้น เลี้ยว ถอยเมื่อ error และ `WAIT_LINE` ที่กลับวิ่งได้โดยไม่ต้อง RESET
ไม่มี BLE หรือ encoder และยังรับคำสั่ง Serial `STOP`

## สเปกและข้อจำกัดของชุดปัจจุบัน

[Tamiya Hyper-Dash 3 Item 15477](https://www.tamiya.com/japan/products/15477/index.html)
ระบุแรงดัน **2.4–3.0 V**, รอบ **17,200–21,200 r/min** และกระแส
**1.6–3.0 A ที่โหลดแนะนำ** ค่า 3.0 A นี้ไม่ได้ระบุว่าเป็นกระแสขณะเพลาติดขัด
หรือขีดจำกัดกระแสเริ่มหมุน

[ST L298 datasheet](https://www.st.com/resource/en/datasheet/l298.pdf)
ระบุ DC absolute maximum **2 A ต่อช่อง**; ตัวเลข 3 A เป็นกรณี non-repetitive
นาน 100 ms จึงใช้แทนพิกัดกระแสต่อเนื่อง 3 A ต่อมอเตอร์ไม่ได้
ข้อจำกัดความร้อนของโมดูลจริงอาจต่ำกว่าขีดจำกัดของ IC อีก

การลด PWM จากแหล่งจ่าย 6.8 V ไม่ใช่การสร้างแหล่งจ่าย 3 V หรือจำกัดกระแส 3 A
และแรงดันตกคร่อม L298 ก็ไม่ใช่ตัวควบคุมแรงดันคงที่
เพดาน PWM 180 เป็นค่าทดลอง ไม่ใช่ค่าที่รับรองว่าชุดนี้รองรับ Hyper-Dash 3

สิ่งที่ต้องจัดให้เหมาะสมในฮาร์ดแวร์คือแหล่งจ่ายมอเตอร์ช่วง 2.4–3.0 V และไดรเวอร์
ที่ทำงานได้ที่แรงดันต่ำนี้ รองรับกระแสใช้งานสูงสุดต่อมอเตอร์ พร้อมเผื่อหรือจำกัด
กระแสเริ่มหมุน เพลาติดขัด และเบรก ต้องตรวจระดับสัญญาณและวิธีควบคุมของบอร์ดใหม่ด้วย
ยังไม่มีข้อมูลไดรเวอร์ตัวใหม่หรือกระแสเริ่มหมุนจริง จึงยังรับรองชุดทดแทนไม่ได้

## สวิตช์เปิดวิ่งและข้อมูลฮาร์ดแวร์

ใน `Settings.h` บันทึกข้อมูลฮาร์ดแวร์ที่ผู้ใช้ยืนยันไว้:

```cpp
const bool ALLOW_UNVERIFIED_MOTOR_POWER = true;
const int MOTOR_SUPPLY_MV = 6800;
const int DRIVER_DC_LIMIT_MA = 2000;
```

`ALLOW_UNVERIFIED_MOTOR_POWER = true` ข้ามเงื่อนไขพิกัดไฟเพื่อให้วิ่งกับค่าที่กรอก
6800 mV / 2000 mA ได้ตามคำขอ ไม่ได้ข้าม Serial STOP หรือการตรวจข้อผิดพลาดอื่น

ตั้งเป็น `false` เพื่อคืนเงื่อนไขเดิม: โค้ดจะไม่เปิด Enable ทั้งสองช่องถ้าแรงดัน
ที่กรอกอยู่นอกช่วง 2400–3000 mV หรือพิกัด DC ต่ำกว่า 3000 mA ต่อช่อง
ชุดปัจจุบันจะแสดง `STATE=MOTOR_POWER_CONFIG` และไฟ L กระพริบเป็นคู่
นี่เป็นเพียงการตรวจข้อมูลที่กรอก ไม่ได้วัดแรงดัน กระแส หรืออุณหภูมิจริง

**แก้ตัวเลขในไฟล์ไม่ได้เปลี่ยนแรงดันหรือเพิ่มพิกัด L298N** ต้องเปลี่ยนฮาร์ดแวร์จริง
และตรวจข้อมูลบอร์ดก่อนปรับค่าคู่นี้ให้ตรงกับชุดใหม่ การผ่านเงื่อนไขในโค้ดอย่างเดียว
ไม่ใช่การรับรองความเหมาะสมของไดรเวอร์หรือการต่อสาย

## เปิดไฟล์

แตก ZIP ทั้งโฟลเดอร์ แล้วเปิด `robotline_hyperdash3.ino` ใน Arduino IDE
เลือก **Arduino UNO R4 WiFi** และเก็บ `Settings.h` ไว้ในโฟลเดอร์เดียวกัน
ไม่ต้องใช้ BLE หรือไลบรารีเสริม

เมื่ออัปโหลดเสร็จจะเริ่มควบคุมมอเตอร์อัตโนมัติ ไม่ต้องแก้ค่าหรือส่ง `START`
ส่ง `STOP` เพื่อหยุดค้าง; ต้องกด RESET จึงเริ่มรอบใหม่

## ค่าจูนใน Settings.h

ค่าต่อไปนี้เป็นค่าเริ่มต้นสำหรับทดลอง ไม่ได้จูนบน Hyper-Dash 3 จริง:

| ค่า | เริ่มต้น |
| --- | --- |
| `BASE_SPEED` ทางตรง | 160 |
| `STEERING_KP` แรงแก้โค้ง | 80 |
| `TURN_SPEED` หมุนเข้ามุม | 180 |
| `SEARCH_SPEED` หมุนหาเส้น | 160 |
| `REVERSE_SPEED` ถอยเมื่อ error | 160 |
| `CROSS_SPEED` ผ่านดำครบห้าจุดช่วงสั้น | 140 |
| `MAX_SPEED` เพดาน PWM ขณะขับ | 180 |
| `RIGHT_TRIM` ชดเชยล้อขวา | 1.0 |

PWM เป็น 0–255 ไม่ใช่โวลต์ แอมป์ หรือ RPM ไม่มีวงจรป้อนกลับควบคุมรอบ
ตัวเลข 17,200–21,200 ไม่ถูกนำมาตั้งเป็นรอบล้อ เพราะยังไม่ทราบอัตราทดและไม่ได้ใช้ encoder
เริ่มสมดุลล้อที่ 1.0 สำหรับมอเตอร์คู่ใหม่ แล้วจูนจากการวิ่งจริง
ทุกค่าความเร็วต้องอยู่ในช่วง 1 ถึง `MAX_SPEED` และเพดานต้องไม่เกิน 255
การเบรกยังใช้ IN1/IN2 HIGH/HIGH และ Enable 255 ตามรุ่นเดิม ไม่ได้อยู่ใต้เพดาน
PWM ขณะขับ และซอฟต์แวร์ไม่ได้จำกัดกระแสระหว่างเบรก

## ขาและการควบคุม

| ส่วน | ขา UNO R4 WiFi |
| --- | --- |
| เซนเซอร์ซ้าย → ขวา | A5, A4, A3, A2, A1 |
| มอเตอร์ซ้าย | PWM D5, ทิศทาง D6 / D7 |
| มอเตอร์ขวา | PWM D10, ทิศทาง D9 / D8 |

ไดรเวอร์ต้องรองรับรูปแบบ Enable/PWM + IN1/IN2 ตาม `setWheel()`:
เดินหน้า LOW/HIGH, ถอย HIGH/LOW, เบรก HIGH/HIGH ขณะ Enable เปิด
ถ้าบอร์ดใหม่ใช้ PH/EN หรือควบคุมต่างออกไป ต้องปรับส่วนนี้ให้ตรงบอร์ดก่อนใช้
ผังขานี้ไม่ได้หมายความว่า L298N เหมาะกับมอเตอร์ตัวใหม่

อ่าน ADC 12 บิต ใช้ค่าพื้น 3000 / ดำ 900 และ threshold 450 จากรุ่นเดิม
ต้องวัดและปรับแยกแต่ละช่องตามจริง
Serial Monitor **115200 baud** แสดง `STATE`, `LAST_ERROR`, `RAW`, `MASK`, `ERR`, `PWM`

ขณะเปิดวิ่ง: error ตามเส้นจะเบรก 80 ms แล้วถอยไม่เกิน 650 ms
เมื่อเจอเส้นปกติจะเบรกก่อนกลับตามเส้น หากยังไม่เจอจะเข้า `WAIT_LINE`
และกลับวิ่งเองเมื่อเจอเส้น `STOP` และข้อผิดพลาดระบบยังหยุดค้างจน RESET

ไฟ L ติดค้าง = ตามเส้น/เลี้ยว, กระพริบเร็ว = ถอย, กระพริบครั้งเดียวต่อวินาที = รอเส้น,
กระพริบเป็นคู่ = STOP/ข้อผิดพลาด รวมถึง `MOTOR_POWER_CONFIG`

## ตรวจซอฟต์แวร์

รันจากโฟลเดอร์ `Robot`:

```sh
python3 robotline_hyperdash3/tests/run_tests.py
arduino-cli compile --fqbn arduino:renesas_uno:unor4wifi --warnings all robotline_hyperdash3
```

ชุดทดสอบใช้ไฟล์ที่แจกตรวจว่าเริ่มสั่งขับได้โดยไม่ต่อ Serial, PWM ขณะขับไม่เกิน `MAX_SPEED`,
เลี้ยว ถอย กลับตามเส้น และ STOP ได้ จากนั้นใช้สำเนาชั่วคราวที่ปิดสวิตช์ข้ามเงื่อนไข
ตรวจว่าค่าฮาร์ดแวร์ที่ไม่ผ่านเงื่อนไขปิด Enable ทั้งสองช่อง และตรวจโค้ดตามเส้น
เมื่อค่าฮาร์ดแวร์ที่กรอกผ่านเงื่อนไข รวม 45 กรณีใน 6 การตั้งค่า
ค่า 3000 mV / 5000 mA ในชุดทดสอบเป็นข้อมูลจำลอง ไม่ใช่การทดสอบไดรเวอร์จริง
การคอมไพล์และผลทดสอบไม่ได้ยืนยันความปลอดภัยทางไฟฟ้าหรือประสิทธิภาพบนสนาม
