# โค้ดเช็กเซนเซอร์ TCR5000L 5 ช่อง

สำหรับ **Arduino UNO R4 WiFi** และสัญญาณแอนะล็อกตามการต่อใน
`robotline_simple` อ่านค่าดิบทั้ง 5 ช่องโดยไม่มีช่วงหน่วงระหว่างรอบ
และส่งข้อมูลทุก 100 ms โค้ดนี้ปิดขาควบคุมมอเตอร์ทั้งสองฝั่งตลอดการทดสอบ

## การต่อสายสัญญาณ

เรียงตำแหน่งเมื่อมองไปทางด้านหน้าหุ่นยนต์:

| เซนเซอร์ | ขา Arduino |
| --- | --- |
| ซ้ายสุด | A5 |
| ซ้าย | A4 |
| กลาง | A3 |
| ขวา | A2 |
| ขวาสุด | A1 |

ใช้สายเลี้ยงและกราวด์ของชุดเซนเซอร์เดิม และกราวด์ร่วมกับ Arduino
ตัวทดสอบนี้อิงเอาต์พุตแอนะล็อกที่ใช้กับโค้ดเดิม ไม่ได้ตั้งสมมติฐานว่า
เลขช่องที่พิมพ์บนโมดูลจะเรียงเหมือนตำแหน่งซ้าย–ขวาของหุ่นยนต์

## วิธีใช้

1. เปิด `sensor_tcr5000l_5ch.ino` ใน Arduino IDE
2. เลือกบอร์ด **Arduino UNO R4 WiFi** และพอร์ต แล้ว Upload
3. เปิด **Serial Monitor** ที่ **115200 baud** หรือเปิด **Serial Plotter**
4. เลื่อนพื้นสีขาวและเส้นสีดำผ่านเซนเซอร์ทีละช่อง โดยรักษาระยะห่างจากพื้น
   เท่ากับตอนติดตั้งใช้งานจริง

ตัวอย่างผลลัพธ์ (ตัวเลขสมมติ):

```text
A5:3000 A4:2980 A3:900 A2:3020 A1:2990
```

ค่าที่อ่านใช้ความละเอียด 12 บิต ช่วง **0–4095** เหมือนโค้ดตามเส้น
ในตัวอย่าง ช่องกลาง A3 มีค่าต่างจากช่องอื่น ให้เทียบกับพื้นจริงก่อนสรุปว่า
ค่าใดเป็นดำหรือขาว ตัวทดสอบแสดงค่าดิบ จึงยังไม่ตัดสินสีจาก threshold

## นำค่ากลับไปจูนโค้ดตามเส้น

- วัดแต่ละช่องเมื่ออยู่เหนือพื้น แล้วจดเป็น `FLOOR_RAW`
- วัดแต่ละช่องเมื่ออยู่เหนือเส้นดำ แล้วจดเป็น `BLACK_RAW`
- เรียงค่าตาม **A5, A4, A3, A2, A1** ใน `Settings.h` ของโค้ดตามเส้น
- ใช้ค่าที่วัดจริงของแต่ละช่อง ไม่จำเป็นต้องเท่ากันทุกช่อง

หากช่องใดไม่เปลี่ยนเมื่อเลื่อนผ่านดำ–ขาว ให้ตรวจสายสัญญาณของช่องนั้น
และระยะติดตั้ง หากค่าค้างใกล้ 0 หรือ 4095 ให้ตรวจด้วยว่าต่อเอาต์พุต
แอนะล็อกอยู่หรือไม่ ค่าที่ปลายช่วงอย่างเดียวไม่เพียงพอจะสรุปว่าเซนเซอร์เสีย

รุ่นนี้อ่านครั้งเดียวต่อช่อง จึงมองเห็นการแกว่งของค่าดิบได้โดยไม่มีตัวกรอง
แต่ข้อมูลที่แสดงทุก 100 ms เป็นเพียงตัวอย่างบางรอบ ไม่ใช่บันทึกทุกการอ่าน

## ตรวจการคอมไพล์

จากโฟลเดอร์นี้:

```sh
arduino-cli compile --fqbn arduino:renesas_uno:unor4wifi --warnings all .
```
