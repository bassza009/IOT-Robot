# หุ่นตามเส้นดำ — UNO R4 WiFi

ตามเส้นดำกว้าง 3.5 ซม. บนพื้นไม้ โดยใช้ TCRT5000 จำนวน 5 จุด
เริ่มควบคุมมอเตอร์ทันทีหลังเริ่มต้นอุปกรณ์และ BLE เสร็จ ไม่มีเวลารอ 5 วินาที
หุ่นวิ่งต่อเนื่องจนได้รับ `STOP` ไม่มีการหยุดตามระยะทางหรือนับรอบอัตโนมัติ
คัดเวลาที่ดีที่สุดจากการวิ่งจริง 3 ครั้งตามกติกาสนาม

## การต่อสาย

ลำดับเซนเซอร์เมื่อมองไปทางเดียวกับหัวหุ่น:

| ตำแหน่ง | ขา Arduino |
| --- | --- |
| ซ้ายสุด | A5 |
| ซ้ายใน | A4 |
| กลาง | A3 |
| ขวาใน | A2 |
| ขวาสุด | A1 |

ตำแหน่งจริงเป็นตัวกำหนดลำดับ ไม่ได้สมมติว่า OUT1 ต้องอยู่ซ้ายสุดของทุกโมดูล
โค้ดอ่านเอาต์พุตแรงดันด้วย ADC 12 บิต และใช้ค่าพื้นไม้/เส้นดำที่กำหนดเองแยกทุกช่อง
รองรับทั้งค่าต่อเนื่องและสัญญาณสองระดับ รวมถึงดำสูง/ดำต่ำ ตามค่าที่ใส่ใน `woodRaw` กับ `blackRaw`
ชนิดวงจรของโมดูล OUT1–5 และช่วงสัญญาณจริงยังต้องตรวจจาก `RAW` บนหุ่น

ใช้การต่อมอเตอร์จากไฟล์ล่าสุดก่อนเปลี่ยนเป็นตามเส้น:

| ล้อ | Enable/PWM | Direction |
| --- | --- | --- |
| ซ้าย | D5 | D6, D7 |
| ขวา | D10 | D9, D8 |
| Encoder ซ้าย | D3 | 20 ช่อง/รอบ ตามค่าของโค้ดเดิม |
| Encoder ขวา | D11 | 20 ช่อง/รอบ ตามค่าของโค้ดเดิม |

เดินหน้า = ขาทิศทางคู่แรก LOW และคู่ที่สอง HIGH
MPU-6050 ถูกนำออกจากโค้ดแล้ว A4/A5 ใช้กับเซนเซอร์เส้น: ถ้ายังมีสาย MPU ต่ออยู่กับขาเหล่านี้ให้ถอดออก

## ตั้งค่าเซนเซอร์แบบ manual

แก้ค่าที่ต้นไฟล์ `LineFollower.h` แล้วอัปโหลดใหม่ ค่าทั้งห้าเรียง A5, A4, A3, A2, A1:

```cpp
int woodRaw[SENSOR_COUNT]  = {3700, 3700, 3700, 3700, 3700};
int blackRaw[SENSOR_COUNT] = {600, 600, 600, 600, 600};
int lineThreshold = 450;
```

ตั้งจากค่าที่รายงาน: พื้นไม้ประมาณ **3700** และเส้นดำ **500–670** โดยเลือก **600** เป็นค่าอ้างอิงดำ
ใช้ค่าเริ่มต้นร่วมกันทั้งห้าช่องก่อน หากแต่ละช่องอ่านต่างกันให้แก้แยกช่อง
ใส่ค่า `RAW` ที่อ่านได้บนพื้นไม้ใน `woodRaw` และบนเส้นดำใน `blackRaw` ทีละช่อง
ค่าต้องอยู่ในช่วง 0–4095 และค่าดำกับไม้ของช่องเดียวกันต้องต่างกัน
ถ้าดำให้ค่าสูงกว่าไม้ ให้ใส่ค่าตามจริงได้เลย ระบบคำนวณทิศทางของช่วงค่าให้จากค่าที่ตั้งไว้
หากตั้งค่าซ้ำกันหรือเกินช่วง จะหยุดด้วย `INVALID_SENSOR_CONFIG`

`lineThreshold` เป็นระดับความดำที่ปรับสเกลแล้ว: ไม้=0 และดำ=1000 ค่าที่ใช้ได้คือ 1–1000
ค่า 450 หมายถึงผ่านจากค่าไม้ไปทางค่าดำ 45% จึงนับว่าเจอเส้น
เมื่อใช้ไม้=3700 และดำ=600 จะนับ RAW ที่น้อยกว่าหรือเท่ากับ 2305 เป็นเส้นดำ

ดู `RAW` ผ่าน Serial Monitor 115200 baud หรือ BLE ขณะหยุด แล้วบันทึกค่าของแต่ละจุด
ส่ง `STOP` ก่อนเก็บค่าเพื่อให้หุ่นหยุดค้าง; เซนเซอร์และรายงานยังทำงานหลัง STOP
วัดที่ความสูงใช้งานจริงเท่ากันทั้งบนไม้และบนดำ โดยวางแต่ละจุดบนพื้นทั้งสองตามลำดับ
หลังวัดเสร็จให้วางหุ่นบนเส้นก่อนกด RESET เพราะหุ่นจะเริ่มทำงานทันทีเมื่อระบบพร้อม
รออย่างเดียวหรือส่ง START จะไม่ปลด STOP
ค่าที่บันทึกลงโค้ดจะใช้ทุกครั้งที่เปิดเครื่อง ไม่มีการเรียนรู้หรือปรับค่าอัตโนมัติ

## เปิดเครื่องและออกตัว

1. วางหุ่นบนเส้นและหันหัวไปตามเส้น ก่อนเปิดเครื่อง/กด RESET
2. หลังเริ่มต้นอุปกรณ์และ BLE เสร็จ หุ่นจะอ่านเซนเซอร์แล้วออกคำสั่งมอเตอร์ทันที
   ไม่มีขั้นตอนกวาดเซนเซอร์ ไม่มีเวลารอ 5 วินาที และไม่รอให้ A3 เจอดำก่อน
   หากเห็นเส้นด้านข้างจะเลี้ยวตามเส้นนั้น รวมถึงกรณีหลายจุดเจอดำพร้อมกัน
   หากยังไม่เห็นเส้นที่ระบุตำแหน่งได้ จะเริ่มเบรกแล้วถอยค้นหาภายในขอบเขตที่กำหนด
3. ขณะวิ่งไฟ L ติด เมื่อ STOP หรือมีข้อผิดพลาดจะกระพริบเป็นคู่
   หุ่นหยุดค้างจนกด RESET ซึ่งจะใช้ค่า manual เดิมและเริ่มทำงานทันทีเมื่อระบบพร้อม

## การตามเส้นและค้นหาเส้น

- ใช้ตำแหน่งเส้นแบบถ่วงน้ำหนักและตัวควบคุม PD ปรับกำลังล้อ
  เมื่ออยู่กลางเส้นต่อเนื่องจึงค่อยเพิ่มความเร็ว ทางโค้งจะลดความเร็วทันที
- ระหว่างตามเส้น หากสัญญาณหายชั่วครู่จะคงคำสั่งล้อก่อนหน้าไว้ไม่เกินช่วงยืนยัน 20 ms
  ถ้ายังไม่พบเส้นเมื่อครบช่วงนี้ จะเข้าสู่การค้นหา ไม่เดินหน้าค้างโดยไม่มีขอบเขต
- เส้นดำที่แยกเป็นหลายกลุ่มจะเลือกกลุ่มที่ต่อเนื่องจากตำแหน่งก่อนหน้า
  หากแยกไม่ออกหรือดำเต็มทั้งห้าจุด จะหยุดการเดินหน้าแล้วเข้าสู่การค้นหา
  เซนเซอร์ห้าจุดยังไม่สามารถรับประกันการแยกเส้นข้างเคียงทุกแบบ ต้องลองจุดที่ห่างกัน 8 ซม. จริง
- เมื่อเห็นรูปแบบมุมจากกลางถึงเซนเซอร์ริม จะเดินช้าให้แกนล้อเข้าใกล้มุมก่อนเลี้ยว
  ระยะเริ่มต้น 4.5 ซม. วัดจาก encoder และจำกัดเวลา 250 ms หาก encoder ไม่ตอบสนอง
- มุมแคบใช้ล้อหมุนสวนกันด้วยกำลังต่ำกว่าค่าเต็ม เพื่อหมุนใกล้ศูนย์กลางหุ่น
  เมื่อเส้นกลับเข้าช่วงที่ตามด้วยการปรับกำลังล้อได้ จะกลับตามเส้นทันทีในรอบอ่านเดียวกัน
  ใช้ได้ทั้งเซนเซอร์ตัวในและคู่เซนเซอร์ โดยไม่มีการหยุดรอยืนยัน A3
  ระหว่างหมุน หากเห็นเส้นเปลี่ยนไปอีกฝั่ง จะเปลี่ยนทิศตามค่าล่าสุดทันที
  เช่น A1 แล้วเป็น A5 จะเปลี่ยนจากหมุนขวาเป็นหมุนซ้าย และจำทิศใหม่ไว้หากเส้นหาย
  ล้อประคองหลังล็อกทิศอาจทำให้การหมุนฝืด ต้องจูนกำลังเลี้ยวจากตัวหุ่นจริง
- หาเส้นไม่เจอจะเบรก 80 ms แล้วถอยช้า ๆ จนพบเส้น
  จำกัดการถอยไว้ **650 ms หรือประมาณ 10 ซม. แล้วแต่ว่าอย่างใดถึงก่อน**
  เมื่อพบเส้นขณะถอยจะเบรก 80 ms ก่อนเปลี่ยนทิศ แล้วตามเส้นหรือหมุนจัดหัวทันที
  ถ้าพบเส้นที่ตามต่อได้ระหว่างเบรกก่อนถอย จะกลับตามเส้นเมื่อครบเวลาเบรกได้เลย
  ถ้ายังไม่พบหรือจัดหัวไม่สำเร็จจะหยุด โดยเวลาค้นหารวมจำกัดไว้ 3500 ms
- Encoder ใช้จำกัดระยะการแก้ทางเฉพาะจุดและแสดงข้อมูล ไม่ใช้ตัดสินว่าครบหนึ่งรอบแล้ว

### เมื่อหลายเซนเซอร์เจอดำพร้อมกัน

ระบบใช้ตำแหน่งของกลุ่มเซนเซอร์ที่เจอดำร่วมกันตั้งแต่เริ่มทำงานและระหว่าง `FOLLOW`
ตารางนี้สมมติว่าจุดที่ระบุเจอดำใกล้เคียงกัน และจุดอื่นอยู่บนไม้:

| จุดที่เจอดำ | การตอบสนอง |
| --- | --- |
| A3 | เดินตรง เพิ่มความเร็วเมื่ออยู่กลางต่อเนื่อง |
| A4 + A3 | ลดกำลังล้อซ้าย เลี้ยวซ้ายอ่อนกว่า A4 จุดเดียว |
| A3 + A2 | ลดกำลังล้อขวา เลี้ยวขวาอ่อนกว่า A2 จุดเดียว |
| A5 + A4 | เลี้ยวซ้ายมากกว่า A4 + A3 |
| A2 + A1 | เลี้ยวขวามากกว่า A3 + A2 |
| A4 + A3 + A2 | เดินตรงเมื่อค่าดำทั้งสองข้างสมดุล |
| A5 + A4 + A3 | เข้าขั้นตอนเข้าใกล้มุม แล้วหมุนซ้าย |
| A3 + A2 + A1 | เข้าขั้นตอนเข้าใกล้มุม แล้วหมุนขวา |
| ทั้ง 5 จุด | เข้าสู่การค้นหาหากระบุตำแหน่งเส้นไม่ได้ต่อเนื่องเกินช่วงยืนยัน |

ซ้าย/ขวามองตามทิศเดินหน้าของรถ โดย A5 อยู่ซ้ายสุดและ A1 อยู่ขวาสุด
กำลังล้อขวายังชดเชยด้วย `rightTrim` จึงไม่จำเป็นต้องมี PWM เท่าล้อซ้ายตอนเดินตรง
การเลี้ยวคำนวณใหม่ขณะตามเส้น ไม่พักระหว่างเปลี่ยนรูปแบบเซนเซอร์
A3 กับ A4 สามารถเริ่มเลี้ยวซ้ายได้ทันทีหลังระบบพร้อม โดยไม่ต้องจัดให้เหลือ A3 จุดเดียว

## BLE และ Serial

- ชื่อ BLE: `IOT-ROBOT` ใช้ Nordic UART Service UUID เดิม
- ส่ง `STOP` ไป RX เพื่อหยุดได้ทุกสถานะ รวมทั้งระหว่างเริ่มระบบ เลี้ยว และถอย
  ส่ง `START` หลัง STOP จะไม่ปลดการหยุด ให้กด RESET เพื่อเริ่มใหม่
- ใช้ Serial Monitor ที่ **115200 baud** ส่ง `STOP` ได้เช่นกัน
- แสดง `MS`, `STATE`, `REASON`, `SENSOR=MANUAL`, `MASK`, `ERR_MILLI`, `PWM_L/R`, `ENC_L/R`, `RAW`, `WOOD`, `BLACK`
  `MS` คือเวลาอ่านข้อมูลชุดนั้นนับจากเริ่มเครื่อง หน่วยมิลลิวินาที
  ค่า RAW/WOOD/BLACK เรียงซ้ายไปขวา; `MASK` เป็นเลขฐานสิบหก โดย bit 0 = ซ้ายสุด
  `ERR_MILLI=-1000` หมายถึงเส้นอยู่ทางซ้ายหนึ่งระยะห่างเซนเซอร์
- BLE TX ส่งทีละไม่เกิน 20 ไบต์ขณะอยู่นิ่ง เพื่อเลี่ยงงานส่งข้อความรบกวนการควบคุมขณะเคลื่อนที่
  BLE RX ยังทำงานขณะวิ่ง ส่วนข้อมูลระหว่างวิ่งดูได้ทาง Serial
  Serial และ BLE ส่งแต่ละชุดจนจบก่อนเริ่มชุดใหม่ แม้สถานะเปลี่ยนระหว่างส่ง
  ข้อมูล BLE อาจมาถึงช้ากว่าเวลาที่อ่าน ให้ดู `MS` ประกอบ; เมื่อมีหลายชุดรอจะเก็บชุดล่าสุดไว้ส่งต่อ
- หาก `USE_BLE=true` แต่ BLE เริ่มไม่ได้ จะหยุดด้วย `BLE_UNAVAILABLE`
  หากการควบคุมขณะเคลื่อนที่ขาดช่วงเกิน 150 ms จะหยุดด้วย `CONTROL_OVERRUN`
  การรับ STOP ผ่านวิทยุยังขึ้นกับเวลาส่งและการเชื่อมต่อจริง

## ค่าจูนหลักใน LineFollower.h

| ค่า | เริ่มต้น | ใช้ปรับอะไร |
| --- | --- | --- |
| `woodRaw` | 3700 ทุกช่อง | ค่า ADC ของพื้นไม้ แยก 5 จุด |
| `blackRaw` | 600 ทุกช่อง (ดำที่วัดได้ 500–670) | ค่า ADC ของเส้นดำ แยก 5 จุด |
| `lineThreshold` | 450 | เกณฑ์ความดำที่ปรับสเกลแล้ว 1–1000 |
| `countdownMs` | 0 | เริ่มทำงานทันทีหลังระบบพร้อม |
| `cruisePwm` | 42000 | กำลังล้อซ้ายเมื่ออยู่กลางทางตรงนิ่งแล้ว |
| `curvePwm` | 34000 | กำลังพื้นฐานตอนออกตัวและเข้าโค้ง |
| `turnPwm` | 40000 | กำลังตอนหมุนหามุม |
| `reversePwm` | 30000 | กำลังตอนถอยค้นหา |
| `rightTrim` | 46800 / 55500 | อัตรากำลังล้อขวา ตามค่าจูนล่าสุดของไฟล์เดิม |
| `steeringKp` | 14000 | แรงแก้ตามตำแหน่งเส้น |
| `steeringKd` | 180 | แรงแก้ตามการเปลี่ยนตำแหน่งเส้น |
| `cornerAdvanceCm` | 4.5 | ระยะเข้าใกล้มุมก่อนหมุน |
| `turnTimeoutMs` | 1800 | เวลาหมุนค้นหาเส้นสูงสุด |
| `reverseTimeoutMs` | 650 | เวลาถอยสูงสุด |
| `reverseMaxCm` | 10 | ระยะถอยสูงสุดโดยประมาณจาก encoder |

PWM มีขนาด 0–65535 ค่าบวกในรายงานคือเดินหน้า ค่าลบคือถอย
ค่า PWM เป็นกำลังที่สั่ง ไม่ใช่ความเร็ว RPM ที่รับประกัน
ความเร็วเริ่มต้นและ PD เป็นค่าตั้งต้นสำหรับทดสอบ ยังไม่ได้จูนบนพื้นสนาม
ถ้ามอเตอร์ไม่หมุนที่กำลังต่ำ ให้เพิ่มเฉพาะค่าของช่วงที่มีปัญหาทีละน้อย
ก่อนเพิ่มเวลาหมุน ให้ตรวจว่าล้อหมุนได้จริงและเซนเซอร์แยกดำ/ไม้ได้ก่อน

เริ่มทดสอบด้วยการยกล้อขับเพื่อตรวจทิศและ STOP แล้วจึงทดลองทางตรง โค้ง และมุมทีละส่วน
เมื่อผ่านสนามซ้ำได้แล้ว ค่อยเพิ่ม `cruisePwm` ทีละขั้น โดยใช้แบตเตอรี่และพื้นทดสอบสภาพใกล้เคียงกัน

ชุดทดสอบใช้ C++ compiler บนคอมพิวเตอร์: g++, clang++ หรือ Zig
ระบุเองได้ด้วย `python tests/run_tests.py --compiler 'C:\path\to\zig.exe'`
ไฟล์ทดสอบคอมไพล์ controller จริงและสเก็ตช์จริง โดยจำลองเฉพาะขอบเขต Arduino/BLE
ครอบคลุมค่า manual สองขั้ว สัญญาณสองระดับ ค่าตั้งผิด ออกตัวทันทีจากทุกตำแหน่งเซนเซอร์
การกลับตามเส้นโดยไม่หยุดรอ สัญญาณหายชั่วครู่ การแก้สองทิศ มุม
เส้นใกล้กัน การถอย/จัดหัว เวลาเกิน STOP ในทุกช่วง และนาฬิกาล้นค่า
การทดสอบเหล่านี้ไม่จำลองแรงเสียดทาน แบตเตอรี่ แสง หรือรูปสนามจริง

ไฟล์เดิมเก็บไว้ที่ `backup/robotcurclerun_raw_before_line_following.ino.txt`
รุ่นที่ใช้คาลิเบรตอัตโนมัติเก็บไว้ที่ `backup/LineFollower_autocal.h.txt` และ `backup/robotcurclerun_raw_autocal.ino.txt`
อย่านำสำเนานี้กลับมาเป็นไฟล์ `.ino` อีกไฟล์ในโฟลเดอร์หลักพร้อมสเก็ตช์ใหม่ เพราะชื่อฟังก์ชันจะซ้ำกัน
